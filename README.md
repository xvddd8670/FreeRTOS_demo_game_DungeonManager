# Dungeon Manager
A demo game for the **STM32F103** microcontroller and an **SSD1306 (I2C)** display.

### Overview
Inspired by *Dwarf Fortress*, *Orbit Industries*, and *Evil Genius*, **Dungeon Manager** is a base-building game where you design, expand, and manage an underground facility.

## Project Goals & Disclaimer

I am developing this project primarily to learn and gain hands-on experience with RTOS (specifically **FreeRTOS**). 

* **Project Scope:** Completing a full game is not the primary goal—delivering a working tech demo would already be a great success.
* **Future Ideas:** I have considered developing a commercial gaming console in the future, but that will only happen if and when I have sufficient resources.
